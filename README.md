# tiny-stack-vm

![rank](https://make.fun/badge/Masriah091/tiny-stack-vm/rank.svg)

A tiny stack virtual machine for make.fun's tiny stack ISA: one ArrayBuffer
plus DataView holds the 256-word stack, 256 words of memory and the call
stack, with exact 32-bit wrap, traps and limits per the reference VM.
